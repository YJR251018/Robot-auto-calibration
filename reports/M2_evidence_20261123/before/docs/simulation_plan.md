# 第一阶段 Eye-in-Hand 仿真实验设计

**状态：待实施协议。本文参数、门槛和趋势均不是已取得的实验结果。**

## 研究问题和边界

首先确认已知真值与非退化位姿下能否正确恢复 `X=T_E_C`，再研究样本数量、噪声和旋转轴覆盖对误差的影响。暂不模拟真实机器人动力学，不声称候选可达、无碰撞或运动时间可靠。

## 1. 无噪声的建模验证

1. 固定真值 X：例如 `R_X=Rz(0.3) Ry(-0.2) Rx(0.1)`，`t_X=[0.05,0.02,0.10]` 米；固定 Y 的 R 为 I、t 为 `[0.6,0,0.3]` 米。数值仅为仿真设置。
2. 使用固定随机种子生成 G_i，覆盖多种非平行旋转轴，排除完全重复或过小相对转角；记录筛选阈值。
3. 严格用 `Q_i=inv(X) inv(G_i) Y` 生成观测，不分别乱生成两组不一致的位姿。
4. 检查所有 `G_i X Q_i≈Y`，并独立检查相对运动 `A_ij X≈X B_ij`。一旦失败先修模型，不能用换求解器掩盖。
5. 核对当前 OpenCV 接口，再传入 G_i、Q_i 的绝对位姿；不要把相对运动数组误传入。
6. 建议首个求解器选择 PARK，TSAI 作比较；先确认本机支持相应枚举和函数，再运行。尚未选定或实现实验。

起始建议为 20 个训练位姿、20 个独立留出位姿；对正常非退化情况，拟以旋转误差 <1e-6 rad、平移误差 <1e-6 m 为无噪声验收门槛。若失败，分析条件数、数值尺度和接口方向，不能事后放宽门槛冒充成功。

## 2. 噪声、数量和退化实验

第一批先做单因素实验，避免所有组合同时铺开：

| 因素 | 建议水平 | 控制 |
| --- | --- | --- |
| 样本量 N | 5、10、15、20、30 | 相同真值、共用大候选集与配对种子 |
| 旋转噪声标准差 | 0、0.05、0.1、0.5、1° | 先只加在 Q，再单独研究 G |
| 平移噪声标准差 | 0、0.1、0.5、1、2 mm | 转成米，三轴独立零均值扰动 |
| 姿态覆盖 | 多轴、近单轴、小角度、纯平移 | 单独标记退化组 |

旋转噪声在 SO(3) 上注入：δθ 的三分量独立服从 N(0,σ_r²)，`R_measured=Exp([δθ]×) R_true`，这里采用左乘，即误差轴表达在目标坐标系中；平移在该目标系做独立相加。σ_r 是旋转向量每分量标准差，不是总转角标准差。不要对 R 的九个元素直接加噪声。
相机观测与机器人测量噪声分开控制；从带噪绝对位姿派生相对运动，它们共享帧而相关，不能把所有帧对当作独立实验样本。

每个非零噪声条件建议 30 个随机种子；报告均值、中位数、标准差、四分位范围和失败率。配对比较时同一 seed 使用同一真值、候选及预生成噪声。失败结果不丢弃，也不以零误差代替 NaN。

## 3. 评价指标

令估计 X̂，真值 X*：

```text
e_R = acos(clip((trace(R_hat R_true.T)-1)/2, -1, 1))
e_t = ||t_hat - t_true||_2
Y_hat,i = G_i X_hat Q_i
```

e_R 内部为 rad，报告时可换算 °；e_t 内部为 m，报告时可换算 mm。
位姿闭环残差分别报告旋转和平移，不直接把单位不同的矩阵元素作无权重总和。
留出点误差用独立 G/Q 及板上点 p_T 计算 `G_hold X_hat Q_hold p_T` 与 `Y_true p_T` 的距离；可先用无噪声留出观测隔离手眼参数误差，再另设带噪部署组，避免混淆。
同时报告求解异常、非有限输出、无效旋转、运行时间及版本。无噪声基线过关不等于达到实机 2 mm。

## 4. 第二阶段再加入视野与采样

位姿级仿真不限制标定板是否在画面中，因此不能据此验证可见性收益。后续增加已知 K、图像大小和板外边界点，要求 z_C>0 且所有边界角点落入带余量图像区域；明确是否有畸变。真实遮挡、模糊和角点提取需另建模型或有真实图像后研究。

共用候选池与初始样本，比较随机、固定顺序、覆盖优先、可见性+覆盖、再加反馈补采。设置相同尝试预算（如 30 次），失败尝试也计数；记录接收率和最终误差。不能一组按有效样本数、一组按总尝试数统计。仿真用程序耗时或明示的运动代价代理，不声称节省了真实机器人采集时间。

## 保存与停止条件

未来每次实验保存配置、种子、真值、带噪原始观测、训练/留出划分、选择顺序、失败原因、输出矩阵和汇总统计。生成不一致、坐标约定未确认或无噪声验证失败时停止策略比较，先排查基础链路。
