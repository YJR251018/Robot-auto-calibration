# 机器人手眼标定基础笔记

## 先理解三个不同问题

相机内参标定估计焦距、主点、畸变等成像参数；PnP 用已知板上三维点与对应像素点估计板到相机位姿；手眼标定利用多帧相机观测与机器人末端位姿，估计相机与末端之间的固定变换。三者的未知量和误差来源不同。手眼结果也不能替代机器人本体的运动学标定。

## 旋转为何不能随便填九个数

旋转矩阵的三列表示 B 系三个单位轴在 A 系中的方向，因此列向量应互相垂直且长度为 1：`R.T R = I`。还需要 `det(R)=+1` 排除镜像反射。例如 `diag(1,1,-1)` 虽然正交，却是反射，不是刚体旋转。

绕 z 轴正向旋转 θ：

```text
Rz(θ) = [[cosθ, -sinθ, 0],
         [sinθ,  cosθ, 0],
         [0,     0,    1]]
```

θ=π/2 时 `[1,0,0]` 变成 `[0,1,0]`。矩阵有效性采用绝对容差，浮点数不应使用逐元素完全相等判断。

## 刚体变换的构造、求逆和组合

```text
T = [[R, t], [0, 0, 0, 1]]
inv(T) = [[R.T, -R.T t], [0, 0, 0, 1]]
T_A_C = T_A_B T_B_C
R_A_C = R_A_B R_B_C
t_A_C = R_A_B t_B_C + t_A_B
```

逆平移需先换到另一个坐标系，因而不是简单的 `-t`。组合时右边先作用；旋转与平移通常不可交换。基础库只接受刚体矩阵，不接受任意投影、缩放或剪切矩阵。

## AX=XB 解的可观测性

从固定板约束得到相对运动方程，推导见 [坐标约定](eye_in_hand_frames.md)。把 R、t 分开可写为：

```text
R_A R_X = R_X R_B
(R_A - I) t_X = R_X t_B - t_A
```

只有平移时 R_A=I，平移方程不能约束 t_X；全都绕相同轴、角度很小或位姿几乎重复时也可能欠约束或病态。采样数多不等于信息充分；必须同时看姿态多样性、旋转轴方向和观测噪声。
经典分离式方法先解旋转再解平移，双四元数等方法可联合处理。不能在未比较噪声模型和数据条件时断言某个求解器普遍最优。方法背景见 [文献调研](literature_review.md)。

## 三类误差必须区分

- 重投影误差：图像平面，单位像素，反映给定模型下的图像拟合。
- 标定重复性：独立重复数据得到的 X 之间差异，分别以角度、米或毫米报告。
- 空间准确度：对未参与估计、具有独立真值的点做坐标转换后的三维误差。

低重投影误差不能单独证明空间准确度高；重复性好也可能存在共同系统偏差。没有真实空间真值时，固定板在基座中的离散只能称一致性指标。
