## C. 独立留出评价

新增一个小而清楚的评价模块，文件名可为 `src/handeye/evaluation.py`。保留已有 pose_error。

### 留出协议

- 每个重复生成一个 60 帧训练候选池和一个 **独立种子生成的 20 帧留出集**，共享同一场景 X/Y；不能把训练的剩余帧伪称为独立生成的留出集。
- 留出位姿绝不参与选择、阈值调节、初值选择或求解。默认留出 G/Q 为理想观测，以隔离手眼估计误差；带噪部署误差属于另一项实验。
- 板上五个参考点以米表示：`(±0.10, ±0.075, 0)` 的四种组合，加 `(0,0,0)`。这是用于空间评价的虚拟板点，今晚不声称投影可见。

### 指标

对留出帧 h 和板点 k：

```text
p_hat_B,h,k = G_h X_hat Q_h [p_T,k; 1]
p_true_B,k  = Y [p_T,k; 1]
d_h,k = ||p_hat_B,h,k[:3] - p_true_B,k[:3]||_2
point_RMSE_m = sqrt(mean(d_h,k ** 2))
```

输出 point_RMSE、最大点误差及每帧误差，报告转换为 mm。另保留 X 的旋转/平移误差，以及 `G_h X_hat Q_h` 对 Y 的旋转/平移残差，不能将其混成一个异单位总和。不要用 4×4 元素最大残差代替空间点误差。

测试至少覆盖：真值估计的零误差；具有已知答案的纯平移扰动；旋转扰动对离轴点产生误差；点集/变换非法输入；输入不被修改。已知数值例子不能全部调用被测函数来生成预期答案。

## D. 三个离线采样策略

新增轻量模块，可为 `src/handeye/sampling.py`。统一输入为候选机器人位姿、候选 ID、初始 ID、目标 N 和选择种子，输出**有顺序、无重复的 ID 序列**与选择日志。选择器不读取 Q、X/Y 真值、误差或留出数据。

共同初始样本固定为候选 ID `[0,1,2,3]`，计入 N；正常候选不足或初始化非法时明确报错，不暗中换种子。

1. **ordered**：初始样本后按候选 ID 顺序补齐。它是顺序对照，不称为真实人工采集。
2. **random**：使用独立种子，对剩余候选无放回抽取，生成一条最大 N 的选择序列。
3. **rotation_farthest**：贪心最大化新姿态与已选姿态间的最小 SO(3) 测地距离；并列时选最小候选 ID。优先使用已有稳定旋转角计算，必要时缓存距离矩阵，避免反复 SVD。

```text
d(R_a,R_b) = principal_rotation_angle(R_a R_b^T) ∈ [0, π]
score(c) = min_{s in selected} d(R_c,R_s)
next = argmax_c score(c)
```

这只是“姿态分散”的启发式代理，不等价于旋转轴可辨识性、信息最优、可达性或最小误差。现有退化检查继续在求解边界生效。

N=8/12/20 必须是**同一条选择序列的前缀**，不能各 N 重新抽样后声称配对。所有策略看到同一候选池和相同初始样本。

测试至少覆盖：固定种子确定性；前缀一致；无重复且 ID 合法；N 超限/非整数/布尔等非法输入；初始 ID 校验；并列稳定；已知小姿态集合的手算选择；共同基座旋转下距离和选择的一致性（避开人为并列）；输入不被修改。检查选择器的数据接口及调用链不接触真值，不用“算法性能一定优于随机”作测试断言。

## E. 冻结实验协议，再运行

### E1. 开发小实验

用开发种子 410000 系列，每条件 2 次重复，先跑完小闭环和故障注入。确认开销、日志、图和再现性。开发数据不并入正式统计。

### E2. 正式协议

建立独立配置，例如 `configs/m2_sampling_v0_1.json`，在查看正式结果前保存配置和代码哈希。默认协议：

| 项目 | 值 |
| --- | --- |
| 场景 | 复用 M1 SceneConfig 的明确真值与分布，不覆盖其配置 |
| 候选数 / 留出帧 | 60 / 20 |
| 样本量 | 8、12、20，均包含 4 个共同初始样本 |
| 策略 | ordered、random、rotation_farthest |
| 求解器 | PARK 为主，TSAI 为参照 |
| 重复数 | 30 个独立重复，i=0…29 |
| 候选 / 留出 / 观测噪声 / 选择种子 | 310000+i / 320000+i / 330000+i / 340000+i |
| 相机观测噪声 | 无噪声；仅旋转 0.3°；仅平移 0.5 mm；混合 0.3°+0.5 mm |
| 机器人位姿噪声 | 正式主实验为 0，扩展实验另设 |

上述 sigma 均为每分量标准差，内部换为 rad/m。先对整个候选池按 ID 生成标准正态噪声表，再按策略选 ID 索引；不能按选择顺序重新产生不同噪声。四种条件用同一噪声表按尺度缩放。

计划总量：`3 策略 × 3 N × 4 噪声 × 30 重复 × 2 方法 = 2160` 次手眼求解。其中 `540` 次为无噪声正式试次；其余 `1620` 次为带噪试次。开发测试、重跑和重放单独记数，不能增加独立统计样本数。

先完成上述 540 次无噪声检查：正常非退化组必须满足原有 `e_R < 1e-6 rad`、`e_t < 1e-6 m`，理想闭环最大元素残差 `< 1e-12`。任一不通过，保存失败与配置并停止依赖它的正式噪声比较；分析是否生成、采样、诊断或求解错误，不偷偷丢种子。专门的退化故障测试不混入正常基线通过率。

在正式运行前测小配置耗时。若确实超出当轮资源，保存被冻结的完整 trial 清单并分批执行；标记 partial 和完成数，不把少跑的试次当作全量，也不选择性只补“结果更好”的条件。

### E3. 统计与图表

每组同时报告 total/success/failed、失败率、旋转/平移/留出点 RMSE 的均值、样本 SD、中位数、四分位数和最大值。成功数不足 2 时 SD 不定义，留空并说明，不能填零。

预先指定主比较：**N=20、混合噪声、PARK 下，rotation_farthest 相对 random 的留出点 RMSE 配对差值**；负值表示前者较低。其他 N、方法与指标作为次要比较，结果全部保留。若做 95% bootstrap 区间，按独立重复编号重采样配对差值，固定 bootstrap 种子与重采样次数（默认 2000）；披露有效配对数和失败率，不能把板点或帧对当独立样本。

至少输出：

1. 误差—N，按策略对比，清楚区分不同噪声/方法；图注说明误差棒含义。
2. 配对差值分布，能看见正、负与接近零的结果。
3. 失败率或成功计数图；零失败也如实显示，不凭空构造失败数据。

有余量可画覆盖分数与误差关系，但只能称探索性相关。不能预先承诺覆盖策略更好，更不能以未优于随机为由改种子或调阈值。
