# M2 实验结果

计划 2160 次，实际 2160 次，成功 2160，失败 0。无噪声 540 次通过。

独立重复单位是 repeat；重放、帧和板点不增加独立样本数。误差汇总条件于求解成功，同时报告失败率。

预设主比较（farthest-random，N20/mixed/PARK）有效配对 30，均值差 -0.31309416137319446 mm，95% 配对 bootstrap 区间 [-0.5573727303439936, -0.09780486238344842] mm。负值表示 farthest 的留出点 RMSE 较低。

error_vs_samples 图为均值±样本SD，不是置信区间；paired 图是按独立 repeat 的配对差值；failure_rate 图保留零失败。

closure_max_abs 只检查实际所选理想 G/Q 的几何闭环。当前是位姿观测仿真，不包含视野、图像、机器人可达性或实际运动时间。
未证明启发式最优或创新性；不同场景与噪声可能推翻当前趋势。
