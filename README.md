# 机器人相机标定工具

面向机器人视觉开发者、现场调试工程师和科研学生，目标是把棋盘格图像与机器人位姿导入同一款工具，完成相机内参与手眼标定。

**开发状态**　当前可运行眼在手上命令行仿真。桌面界面、相机内参标定和两种手眼模式的数据导入功能在开发计划中。

## 功能

| 功能 | 输入 | 输出 | 进度 |
|---|---|---|---|
| 眼在手上仿真 | 脚本生成的 15 组位姿，可设置视觉平移噪声 | 已知和估计的相机安装位置、平移误差和旋转误差 | 可运行 |
| 单目相机内参标定 | 棋盘格照片、内角点行列数和方格边长 | 相机内参矩阵、畸变系数、逐帧重投影误差 | 计划 |
| 眼在手上标定 | 末端安装相机，棋盘格固定。导入已有或软件计算的相机内参、照片和对应的机器人实际末端位姿 | 从相机坐标系到机器人末端坐标系的变换 | 计划 |
| 眼在手外标定 | 相机固定，棋盘格装在机器人末端。导入已有或软件计算的相机内参、照片和对应的机器人实际末端位姿 | 从相机坐标系到机器人基座坐标系的变换 | 计划 |
| 采样位姿推荐与补采 | 初始标定、候选位姿和实拍质量 | 下一拍建议、复拍或换位决定、质量日志 | 计划 |

桌面软件首版计划提供三个入口，分别对应单目内参、眼在手上和眼在手外标定。用户可用随附样例完成标定，并导出带坐标方向、长度单位和样本质检记录的结果。

## 安装与运行

### 环境要求

当前仿真已在 **Windows 11、PowerShell、Python 3.12 和 NumPy 2.4.6** 环境下验证。仿真直接生成位姿数据，运行时只需要 Python 和 NumPy。后续图像处理计划采用 OpenCV，用于棋盘格角点检测、内参标定和 PnP 位姿估计。

### 安装依赖

在项目根目录打开 PowerShell，确认 `python` 指向 Python 3.12，然后安装已验证的版本。 [NumPy 2.4.6 发行包](https://pypi.org/project/numpy/2.4.6/)

```powershell
python --version
python -m pip install numpy==2.4.6
```

### 运行仿真

```powershell
python .\first_handeye_experiment.py
python .\first_handeye_experiment.py --noise-mm 1
python .\first_handeye_experiment.py --help
```

第一条命令用理想数据检查求解能否恢复已知的相机安装位姿。第二条命令给视觉位姿的每个平移分量加入标准差为 1 mm 的噪声。最后一条命令显示参数说明。

| 仿真设置 | 平移误差 | 旋转误差 |
|---|---:|---:|
| 无噪声 | 0.000000 mm | 0.000000° |
| 视觉平移噪声 1 mm | 1.909793 mm | 0.000000° |

以上是脚本固定随机种子下的示例输出，按六位小数显示。第二组只给平移分量加噪，旋转输入保持理想。实机表现由后续独立实验评估。

## 开发路线

1. **验证两种配置。** 先在眼在手上仿真中比较旋转方向集中与分散的采样，再为眼在手外补充已知真值样例。
2. **完成桌面软件首版。** 实现单目内参标定、两种手眼模式、数据导入、结果查看与导出。
3. **接入实机数据。** 先导入人工采集的照片和实际末端位姿，核对配对关系、坐标方向和长度单位。控制接口开放后，再接入自动运动与拍摄。
4. **验证采样方法。** 在眼在手上配置中，比较人工选点、固定轨迹和基于可见性与旋转覆盖的筛选及补采。统一初始样本、求解器和最多拍摄次数，失败拍摄及复拍计入预算。记录有效样本率、采集耗时、重复性和独立验证误差。

实机实验计划每组取得至少 15 组有效位姿。具备独立基座坐标参考和测量条件时，以验证点平均三维位置误差 2 mm 以内为争取目标。

固定轨迹基线参考冯东远《打磨机器人工具工件高精度自动标定系统开发》（广东工业大学，2025）第 3.4 节。
