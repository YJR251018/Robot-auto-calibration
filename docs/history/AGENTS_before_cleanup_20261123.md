# 项目开发约定

## 目标与当前阶段
- 面向机械专业本科生的机器人自动手眼标定科研项目。
- 使用 Windows、Python、NumPy、SciPy、OpenCV、Matplotlib、pytest。
- 当前仅完成环境和目录初始化；未实现 Eye-in-Hand 求解、自动采样或位姿规划。
- 后续按 Eye-in-Hand 仿真、自动采样、位姿规划的顺序逐步推进，每阶段等待明确任务。

## 开发方式
- 用中文解释关键步骤，区分计划、实际执行和检查结果。
- 遇到错误先定位原因，再提出修复方案；不要用虚构数据掩盖失败。
- 保持结构简单：代码放 src/，测试放 tests/；暂不引入 GUI 或机器人硬件控制。
- 使用项目内 .venv，不向全局 Python 安装项目依赖。
- 安装 Python、Git 或修改系统设置前，先说明并取得用户许可。
- 保留文献、申报书及用户已有改动；不自动恢复删除文件、提交、重置或清理仓库。

## 验证与复现
- PowerShell：`.\.venv\Scripts\python.exe -m pytest -q`。
- 新功能应有能验证实际行为的适量测试；不提前编写尚未授权的算法。
- 更新依赖后执行导入测试，并用 pip freeze 更新 requirements-lock.txt。
- 未来涉及位姿时，须明确坐标系、变换方向、矩阵约定、角度和长度单位，并在文档和测试中保持一致。
