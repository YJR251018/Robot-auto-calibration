# 未来研究问题与可能创新点

**以下全部是待验证假设，没有对应的已实现策略或性能成果。**
主动选视角和自动标定已有研究，不能仅凭“加入可见性”或“自动规划”就声称首创。先建立可复算基线，再收窄项目可实现的问题。

| 假设 | 可检验的比较 | 可能推翻它的情况 |
| --- | --- | --- |
| H1 先筛视野可提高有效样本率 | 相同候选、初值和总尝试预算；可见性开/关 | 初值偏差使有价值视角被错拒，或原候选已全可见 |
| H2 旋转覆盖优先可改善小样本重复性 | 固定求解器；覆盖排序 vs 随机/固定顺序 | 视觉噪声上升抵消激励收益，或几何本来已充分 |
| H3 按失效原因补采优于盲目复拍 | 固定失败模型和预算；原因关联补采 vs 随机补采 | 失效分类不准、补采代价过高或失败非独立 |
| H4 保守可见性余量可缓解粗标定偏差 | 分档注入初值偏差，比较固定余量与不确定性余量 | 余量过大导致样本不足、保留下来的运动接近退化 |
| H5 简单覆盖代理有合适的精度/代价折中 | 与已复现的信息增益方法在同预算比较 | 代理与参数不确定性无关或计算节省可忽略 |

## 怎样让项目主张站得住

1. 对照共用候选池、初始样本、求解器和配对噪声；初始人工样本也计入预算。
2. 消融拆开可见性、覆盖、质量反馈，避免只比较“全套方案”与弱基线。
3. 多种子统计，公开失败和负结果；不只挑最佳一轮。
4. 将旋转轴视为无方向轴线，用 `acos(clip(abs(u·v),0,1))` 比较；必须先把不同运动的轴转换到同一表达坐标系，并排除接近零转角的未定义轴。
5. 分别检查绝对真值误差、闭环一致性和有效率；不把优化代理的改善直接写成空间精度改善。

## 优先级建议

先做 H2 的位姿级实验，成本最低；投影模型正确后研究 H1 与 H4；有可解释的失败模型后再做 H3。H5 需要先阅读并复现 NBV 类方法，难度较高，不作为第一阶段交付门槛。
明天建议先确定仿真求解器和无噪声验收标准；硬件采购、GUI 和机器人控制暂不进入开发队列。
